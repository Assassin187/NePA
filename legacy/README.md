# Legacy NePA specification drafts

This directory preserves the pre-v2.0 three-file specification model exactly as
required by M0-2. These files are historical inputs, not active schemas or gold
assets.

- `schemas/`: wire-format, requirements, and generation-profile schemas.
- `gold_specs/`: MQTT 3.1.1 instances of those schemas and their original notes.
- `migration-to-spec-ir-v2.md`: deterministic field-level migration map.

Active schemas live under `nepa/schemas/`; active gold assets live under
`golds/mqtt-3.1.1-min/`.
