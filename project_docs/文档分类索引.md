## 四、文档使用边界

- 当前工程的规范性设计来源是 [system_design.md](system_design.md)。
- 当前实现和验收进度主要查看 [engineering/重构计划](engineering/重构计划.md)。
- 研究报告用于提出和论证方向，实验报告用于提供证据，二者都不能未经裁决直接覆盖 `system_design.md`。
- `engineering/重构删除台账.json` 虽然不是 Markdown，但属于重构工程台账，和 `engineering/重构计划.md` 配套使用。
